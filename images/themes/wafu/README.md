# Tikfinity 和風UI素材パック（個別透過PNG）

全19点。藍色・金色・桜・和風の統一デザイン。すべてRGBA PNG、外側の背景は透明です。

## 組み込み
既存の `images/themes/wafu/` の画像をバックアップし、同名PNGを置き換えてください。
既存の `theme.json` / `theme.css` は上書きしないでください。
画像の内側の余白、カード窓、ルーレット穴、タイトル文字の位置を実機プレビューで再確認してください。
ルーレットの候補・確率・結果・送信者名は従来どおり動的描画してください。
`counter-badge.png`、`test-badge.png`、`button.png` は文字なしです。文字はHTML側で表示してください。

## 注意
カード枠は以前の単体透過PNGを再利用しています。全素材は視覚的な統一を目指した試作で、既存テーマの座標に完全一致する保証はありません。
