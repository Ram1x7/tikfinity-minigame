# らみん民 LIVE Overlay（初期実装）
既存のミニゲームを壊さない、読み取り専用の独立オーバーレイです。

## URL
- `overlay/display.html?demo=1` : Firebaseに接続しないデモ
- `overlay/display.html?env=prod` : 本番キューの新規受信を表示
- `overlay/display.html?env=test` : 既存テスト用キューの新規受信を表示

PRISM LIVEのWebソースは1080×1920推奨。背景は透明です。

## 現在できること
- ギフトキューの新着をリアルタイム監視し、通知を表示
- 画面を開いてからの受信件数と送信者別ランキング
- いいねペット・出席スタンプのUI（イベント未連携）
- Firebaseを使わないデモ表示

## 重要な制約
- 既存キューはギフトごとに抽選結果を格納します。件数はギフトの個数・ダイヤ額ではなく、キューに追加されたイベント数です。
- ランキングと件数はページのリロードでリセットされます。永続集計にはWorkerとFirebaseの追加実装が必要です。
- このページは既存の再生カーソルを更新せず、ガチャ・ルーレットの再生担当にもなりません。
- 既存の`database.rules.json`、Worker、`main`、Firebaseの実データは変更していません。
- いいね・フォロー・コメント・出席イベントは現在のギフトWebhookでは受け取れません。受信形式を確認してから接続します。
