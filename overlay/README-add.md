# 統合表示ページ

`overlay/combined.html?env=prod` は、既存の `display.html` と新しい `overlay/display.html` を1つのPRISMブラウザソースに重ねるラッパーです。

- 既存ガチャ・ルーレットの処理は変更せず、元の表示ページをiframeで開きます。
- 追加オーバーレイは透明なiframeで前面に重ねます。
- クエリ文字列は両方のページへ渡すため、既存の表示キーなどのパラメータも同じURLに指定します。
- 既存表示ページがiframe内での実行を許容するか、PRISM LIVEで音が鳴るかは実機検証が必要です。
- iframeの積み重ねによりガチャ演出が一部隠れる可能性があります。現段階では配置調整未実施です。
- `?demo=1` は追加オーバーレイのデモのみを切り替えます。既存ゲームのデモモードを意味しません。
