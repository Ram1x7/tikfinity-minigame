接続設定(この端末に保存)

表示用の合言葉は PRISM LIVE に設定する表示画面の URL に入ります。管理用の合言葉とは別の値にしてください。

    URL の案内

    PRISM LIVE に追加する表示画面の URL(「表示の調整」の設定を含みます)。表示用の合言葉は伏せて表示しています。コピーすると合言葉入りの URL になるので、人に見せたり配信に映したりしないでください

    TikFinity の Webhook に設定する URL(「合言葉」の部分を Worker の WEBHOOK_KEY に置き換え)

    表示画面の再生担当

    同じ環境で再生する表示画面は1つだけです。別の表示画面(PRISM など)に切り替える時は、担当を外してください。待機中の画面が10秒ほどで引き継ぎます。待機中の画面が無いと、最大30秒ほど再生が止まります。
