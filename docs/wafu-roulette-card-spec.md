# 和風ルーレット 結果カード(1200×540)素材仕様書

ルーレットが止まった後に出す「横長の結果カード」の正式素材の仕様です。
今の仮素材 `banner-*.png`(1200×360)は、この素材に切り替わるまで残します(上書き・削除しない)。

- 確定日: 2026-10-19 / 対象ブランチ: `wafu-roulette-work`
- 配置のガイド画像: [`wafu-roulette-card-guide.png`](wafu-roulette-card-guide.png)(1200×540・透過。制作時に重ねて使う)

## 1. 基本仕様

| 項目 | 内容 |
|---|---|
| 画像サイズ | **1200×540px**(縦横比 2.22:1) |
| 形式 | PNG・RGBA・sRGB(色の埋め込みプロファイルは sRGB か無し) |
| 枚数 | 4枚(N・R・SR・SSR) |
| 文字 | **景品名・送信者名・「さん」などの文字は画像に入れない**(HTML で重ねる)。レア度の文字(N/R/SR/SSR)はバッジの中に入れてよい |
| 表示の大きさ | 画面(1080×1920)で幅 900px(0.75 倍)。iPad の PRISM LIVE ではさらに約 0.74 倍 |
| 目安の容量 | 1枚 600KB 以下(4枚で 2.4MB 以下) |

## 2. 座標(画像の左上が 0,0。単位 px)

| 領域 | 範囲 | 決まり |
|---|---|---|
| 枠の本体 | x 36〜1164、y 32〜508(1128×476)、角丸 28 | 本体の外は透明(下の「透明部分」) |
| **景品名の安全領域** | **x 168〜1032、y 97〜362(864×265)** | 装飾・バッジ・桜・強い光沢を**置かない**。背景の色と、ごく弱い模様だけ |
| 仕切り線 | y 368〜376 の中に、x 240〜960 の細い線(2〜4px) | 景品名と送信者名の境目。安全領域には入れない |
| **送信者名の帯** | **x 144〜1056、y 383〜454(912×71)** | 装飾を置かない。帯の地の色は景品名の領域と同じか、少し暗い色 |
| レア度のバッジ | 円の中心 (70, 66)、直径 124 以下(x 8〜132、y 4〜128) | 本体の左上の角に重ねる。**x 150・y 140 を越えない** |
| 右上の装飾 | x 1060〜1164、y 32〜112 | 桜・金箔・渦巻きはこの中だけ |
| 左下の装飾 | x 36〜140、y 428〜508 | 同上 |
| 右下の装飾 | x 1060〜1164、y 428〜508 | 同上 |
| 縁の帯 | 本体の外周から内側 30px まで | 金属の縁・二重線・細い模様を置いてよい(安全領域にかからない範囲) |

**侵入しないことの確認**(どの装飾も文字の領域と重ならない):

- バッジの右端 132 < 景品名の左端 168、バッジの下端 128 < 送信者名の帯の上端 383
- 右上の装飾の左端 1060 > 景品名の右端 1032
- 左下の装飾の右端 140 < 送信者名の帯の左端 144、右下の装飾の左端 1060 > 帯の右端 1056
- 縁の帯(本体の内側 30px)は、景品名(本体から左右 132px・上 65px 内側)・帯(本体から下 54px 内側)より外

## 3. 透明部分

- 本体(x 36〜1164、y 32〜508)の外は**完全に透明(alpha 0)**。
  ただし本体の外側 20px 以内に、ごく弱い光(alpha 40% 以下)を付けてよい。
- 本体の地は **alpha 240〜255(94% 以上)**。配信画面のゲームが透けて文字が読みにくくならないように。
- 景品名の安全領域・送信者名の帯の中は、**alpha 245 以上**にそろえる(透け方のむらを出さない)。
- バッジは本体からはみ出す部分も含めて不透明。ふちはアンチエイリアス。

## 4. レア度ごとの配色・装飾・光沢

文字の色は表示側で決まっている: 景品名 `#fff6dc`(SSR は `#ffe9a8`)、送信者名 `#f3e3b3`、どちらも濃い影付き。
**安全領域の中で最も明るい色でも、文字とのコントラスト比 7:1 以上**になる濃さにする(下の地の色はこれを満たす)。

| | N(白銀) | R(水色・緑) | SR(紫) | SSR(金) |
|---|---|---|---|---|
| 本体の地(上→下の濃淡) | 藍 `#141d3d` → `#24315e` | 深い青緑 `#0b3533` → `#155a52` | 深い紫 `#22113f` → `#3c2170` | 深い茶金 `#2a1708` → `#4d2f12` |
| 外側の金属の縁 | 銀 `#eef2f8` → `#aab4c4` → `#6f7a8c`(白銀) | 金 `#f3dc9a` → `#c9a14a` + 内側に翡翠の細線 `#74d9c9` | 金 `#f3dc9a` → `#c9a14a` + 内側に藤色の細線 `#c49af0` | 濃い金 `#fff2c4` → `#e3b54a` → `#a77a22`、縁を2重にして最も太く |
| 内側の細線(本体から 18px) | 銀 3px(不透明度 60%) | 金 3px | 金 3px | 金 4px + 外側に薄い光 |
| バッジ | 紺の円に銀の輪、文字 N は白銀 | 紺の円に翡翠の輪、文字 R | 紺の円に藤色の輪、文字 SR | 紺の円に金の二重輪、文字 SSR は金 |
| 四隅の装飾 | 白銀の小さな光の粒(**桜は入れない**) | 水色・白の小花と小さな光の輪 | 桜(淡い桃 `#f4aac8`)と紫の光 | 桜・金箔・金粉。3か所の中で最も華やかに |
| 光沢・金属感 | 控えめ(縁の上辺に細いハイライト 1本) | やや控えめ | 中程度(縁の上辺と左上の角にハイライト) | 最も強い(縁全体に鏡面のハイライト、角に小さな輝き) |

共通の決まり:

- 光沢・ハイライト・模様は**縁の帯と四隅の装飾の中だけ**。安全領域の中に白い光(alpha 30% 超)を置かない。
  表示側で、カードが現れたときに光が1回走る演出を重ねるため、画像の光沢は控えめでよい。
- 和柄(青海波など)を地に入れる場合は、安全領域の中では明るさの差 10% 以内(文字の読みやすさを優先)。
- ガチャの結果カード(`card-*.png`)・宝珠の演出と同じ配色の方針(N 白銀 / R 水色・緑 / SR 紫と桜 / SSR 金)にそろえる。

## 5. ファイル名と theme.json との対応

推奨ファイル名(`images/themes/wafu/` に置く。今の `banner-*.png` とは別の名前):

```
roulette-card-n.png
roulette-card-r.png
roulette-card-sr.png
roulette-card-ssr.png
```

theme.json(`images/themes/wafu/theme.json`)の `rouletteCard` を次に差し替える。数値は画像に対する %:

```json
"rouletteCard": {
  "frames": { "N": "roulette-card-n.png", "R": "roulette-card-r.png", "SR": "roulette-card-sr.png", "SSR": "roulette-card-ssr.png" },
  "body": { "left": 3, "right": 3, "top": 6, "bottom": 6 },
  "text": { "left": 14, "right": 14, "top": 18, "bottom": 33 },
  "sub":  { "left": 12, "right": 12, "top": 71, "bottom": 16 },
  "width": 900,
  "ringOverlap": 0.3
}
```

| theme.json | 画像の座標 | 意味 |
|---|---|---|
| `body` 3 / 3 / 6 / 6 | x 36〜1164、y 32〜508 | 本体。当選時の光をここのふちに合わせる |
| `text` 14 / 14 / 18 / 33 | x 168〜1032、y 97〜362 | 景品名(最大4行、原則 40px 以上。表示側で 60〜78px から合わせる) |
| `sub` 12 / 12 / 71 / 16 | x 144〜1056、y 383〜454 | 送信者名(1行。34px から最小 26px、それでも長ければ末尾を …) |
| `width` 900 | — | 画面(1080×1920)でのカードの幅 |
| `ringOverlap` 0.3 | — | 止まった後、盤面の下側 30% までカードで隠す(針の下の当たりと中心は見える) |

4枚のうち1枚でも読み込めないときは、従来の結果枠(`result-frame.png`)に自動で戻る。

## 7. 新素材への切り替え手順

1. 4枚を `images/themes/wafu/roulette-card-{n,r,sr,ssr}.png` に置く(既存の画像は上書きしない)。
2. 素材の確認(下の「素材の確認項目」)。
3. theme.json の `rouletteCard` を「5」の内容に差し替える。
4. `npm test`・`npm run check`・`node tests/browser/smoke.mjs` を実行する。
5. N・R・SR・SSR × 短い景品名・41文字・48文字・長い送信者名のスクリーンショットで確認する。
6. 作業ブランチに push → Cloudflare Pages の開発ブランチで確認 → iPad の PRISM LIVE で確認。
7. 問題がなければ、`banner-*.png` を残すか削除するかを決める(切り替え完了までは残す)。

## 8. 素材の確認項目

- [ ] 4枚とも 1200×540・RGBA・PNG
- [ ] 本体の外(四隅など)が透明(alpha 0。外側 20px 以内の弱い光を除く)
- [ ] 本体の地の alpha が 240 以上、安全領域・帯の中は 245 以上
- [ ] 景品名の安全領域・送信者名の帯に、装飾・バッジ・桜・強い光沢が入っていない
- [ ] バッジが x 150・y 140 を越えていない
- [ ] 四隅の装飾が決められた範囲(右上・左下・右下)の中だけ
- [ ] 安全領域の最も明るい色でも、文字(`#fff6dc`)とのコントラスト比 7:1 以上
- [ ] 画像の中に景品名・送信者名などの文字が無い
- [ ] N に桜が入っていない。SSR が最も華やか
- [ ] 1枚 600KB 以下

## 9. 表示のテスト項目

- [ ] N・R・SR・SSR で、それぞれの枠が出る
- [ ] 景品名が安全領域の中に収まり、装飾・バッジに重ならない(短い・41文字・48文字)
- [ ] 送信者名が帯の中に1行で出る(長い名前で全文、または末尾の …)
- [ ] カード表示中は見出しの送信者名と、結果一覧の最新1件が隠れる(重複しない)
- [ ] 回転中は見出しに送信者名が出る
- [ ] 止まった後、当たりの扇形と中心が見える。盤面の直径が 1080×1920 換算で 500px 以上
- [ ] 候補が多い盤面(番号表示・下の候補名)でも、候補名とカードが重ならない
- [ ] 9:16 の画面で、コメント欄よけ 1100 / なし / 台紙なし のどれでも見切れない
- [ ] 1枚欠けたときに従来の結果枠に戻る
- [ ] 完成済みのガチャ・Classic テーマが変わらない
- [ ] iPad の PRISM LIVE で、透過・文字の読みやすさ・発熱を確認
