# 第2段階・宝珠分割開封（作業ブランチ専用）

このブランチは `wafu-preview` から分岐した開発用です。まだ `wafu-preview` / `main` にマージしないでください。

## 実装状況
- `theme.json` に `orbParts`（closed/lid/base/core/energy/petals/sparkles）を追加。
- `js/theme.js` で7枚を読み込み、**全て正常に読み込めた場合だけ** `theme.orbParts` を有効化。
- `js/play-gacha-image.js` に上蓋・下半球・光球・エフェクトの分割アニメーションを追加。
- `theme.css` に和風限定の位置合わせとSSR昇格色を追加。
- 画像がない場合は従来の capsule 2枚による演出に戻る。

## 画像の追加（済）


**注意:** 上蓋と下半球は閉じた宝珠と完全には一致しません。拡大や変形でごまかさず、まず実画面で確認してください。

## 検証で直したこと
- 上蓋: 元の動き（上へ28%・左へ9°）では、開いた形の上蓋が下半球の口と光球を覆っていた。
  下半球の右奥を支点に開いたように、右上へ持ち上げて 0.8 倍にする（`translate(10%, -43%) scale(.8)`）。
  見出し（「1 / 2 回目」）には重ならない。
- 光球: 上蓋の下に隠れていたため、下半球の口の高さ（箱の上から40%）に置き、下から膨らむように出す。
- 素材の切れ端: 下半球の左端の房の切れ端（x 12〜29px）を `clip-path` で隠す。
  光の輪の上部にある飾りの切れ端も隠す。花びら・きらめきは素材の端で直線に切れて見えるため、周りをぼかす（mask）。
- SSR の昇格: 全体に `filter: drop-shadow` をかけていた（iPad で毎フレーム再描画になり重い。紫の時間は 0.28 秒だけ）。
  紫と金の光（放射状のグラデーション）を別の要素にし、不透明度だけを動かす。
  紫の予兆は揺れている間に SR・SSR で同じように出し、開いた瞬間に SSR だけ金へ変わる（開くまで SR か SSR か分からない）。
- `theme.json` の書式が全体的に組み替えられていたのを元に戻し、`orbParts` の追加だけにした。

## レア度ごとの演出（確定した方針）
| レア度 | 開く前 | 開いたとき（宝珠） | 札が出たあと（js/effects.js） |
|---|---|---|---|
| N | 予兆なし | 白銀の控えめな光と光粒（光球・きらめきを銀色に）。桜なし | 銀の粒 4 個。桜なし |
| R | 予兆なし | 水色・緑の光と小さな光の輪（光の輪を 0.78 倍・水色に） | 水色の粒 5 個。桜なし |
| SR | 紫の予兆 | 紫の光・紫の光の輪・桜の花びら | 紫の粒 6 個・桜 10 枚 |
| SSR | SR と同じ紫 | 金へ昇格。光の輪・桜・きらめき・金粉（きらめきをもう1枚）・大きな金の光 | 光の筋・桜 18 枚・金の粒 16 個 |

- 出す部品は `theme.json` の `orbRarity`、色・大きさは `theme.css` の `.wafu-orb[data-rarity]`、
  札が出たあとの演出は `theme.json` の `effects` で決める。
- 色は画像に静止した `filter` をかけて変える（動かすのは不透明度と位置だけ）。

## 素材の差し替え方
- 部品の画像は `theme.json` の `orbParts` に書く。切れ端を隠す暫定の補正（`clip` / `softEdge`）は
  画像ごとに同じ場所に書いてある。
  ```json
  "base": { "file": "orb-open-base.png", "clip": "inset(0 0 0 7%)" }
  ```
- 切れ端を直した PNG に差し替えるときは、`file` を変えて、その行の `clip` / `softEdge` も消す
  （文字列だけの `"base": "orb-open-base-v2.png"` に戻せばよい）。
- 7枚のうち1枚でも読めなければ、従来の玉の画像（capsule-closed / capsule-open）で演出する。
- 読み込みは `js/orb.js`（DOM に依存しない。テストは `tests/orb.test.js`）。

## レア度ごとの結果カード（仮実装）
- 素材: `card-n/r/sr/ssr.png`（1000×1200）を `theme.json` の `resultCard` で使う。
  4枚すべて読めたときだけ使い、1枚でも欠ければ従来の札（`card-frame.png`）に戻る。
- 上の大きな枠に景品名、下の枠に「送信者名 さん」を HTML の文字で重ねる。
  レア度の印は枠の画像に描かれているので、HTML のバッジは出さない。
- 文字の場所（`label` / `sub`）は四隅の渦巻きと SR・SSR の桜を避けた範囲（画像に対する %）。
  札の高さ 880px（本体は約 728px で、和風の再生の枠 760px に収まる）。
- 読み込みは `js/result-card.js`（テストは `tests/result-card.test.js`）。

## 素材について（制作側への連絡事項）
- `orb-open-base.png` の左端（x 12〜29px）に房の切れ端がある（表示では隠している）。
- `orb-energy.png` の上部（y 88〜128px 付近）に飾りの切れ端がある（表示では隠している）。
- `orb-petals.png` / `orb-sparkles.png` は絵が画像の端まで描かれていて、そのままだと直線で切れる。
- 上蓋・下半球は閉じた宝珠と形が一致しないため、開く瞬間はクロスフェードで切り替えている。
