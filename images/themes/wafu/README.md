# Tikfinity 和風UI素材（試作・切り出し版）

画像生成した素材一覧から切り出した試作用PNGです。個別生成された厳密な素材ではありません。元画像の背景色や隣接する装飾が一部残る可能性があります。透過領域は幾何学的マスクによる近似です。**配信前に必ずプレビューで確認してください。**

- カード枠 1000×1500、タイトル帯 700×206、カプセル各400×400、結果枠 940×440、ルーレットリング800×800、針120×220。
- ルーレットリングの中央は透過。可変候補の盤面はCanvas/SVGで描画すること。
- テキスト・ギフト名・送信者名・残り件数・確率・レア度は動的HTMLで描画すること。
- この素材は **試作**。細部を確認してから採用し、実装ロジック・Firebase・Workerは変更しないこと。
